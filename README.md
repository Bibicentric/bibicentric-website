# Bibicentric artist website

Static artist website. GitHub Pages serves index.html and assets from the main branch.

Primary homepage: https://bibicentric.github.io/

The project-site copy at https://bibicentric.github.io/bibicentric-website/ remains available. Both copies use the root homepage as their canonical URL.

The main page includes responsive WebP images, click-to-load music and video players, native expandable archives, and booking/press downloads. Original photos are retained for press downloads. Media links work as external links when JavaScript is disabled.

The local checkout has two remotes: `short` for `Bibicentric/bibicentric.github.io` and `github` for `Bibicentric/bibicentric-website`. Push updates to both to keep the compatibility copy current.

The biography and media references come from the supplied website. Photographer credits, event availability, performance lineup, pricing and the technical rider must be confirmed directly with the artist.
